# AI-support-T2DM

Ứng dụng AI hỗ trợ tự quản lý đái tháo đường type 2 thông qua:
- Tư vấn tri thức dựa trên nguồn y khoa đáng tin cậy
- Gợi ý dinh dưỡng
- Giám sát tư thế tập luyện bằng Computer Vision

Cấu trúc:
- Docs: tài liệu dự án
- backend: API và server
- frontend: giao diện người dùng
- ai: LLM/RAG/AI services
- computer-vision: MediaPipe Pose và exercise analysis
- database: PostgreSQL schema, migration, seed
- dataset: dữ liệu phục vụ phát triển và đánh giá
- tests: kiểm thử
